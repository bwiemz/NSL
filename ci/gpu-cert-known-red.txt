# GPU certification lane — known-red gates
# =========================================
#
# Gates listed here are ALLOWED to fail without failing the lane. Everything
# else that is not PASS makes `scripts/gpu-cert.sh --run` exit 1.
#
# The posture is deliberate. The first full run found breakage that pre-dated
# the lane, and blocking on all of it would have meant the lane could never go
# green — so it would have been switched off within a week. Instead:
# pre-existing red is recorded here with evidence, and any NEW red fails.
#
# EVERY entry below was verified against origin/main (1e86f101) in a separate
# worktree before being written here. None is a regression from the roadmap
# campaign; "it was failing when I got here" is the point of the file, but it
# had to be MEASURED, not assumed.
#
# Deleting a line is how a fix gets locked in — the lane then enforces that
# gate forever after.
#
# Format (tab-separated, matching the report's first two columns):
#   <cargo target args><TAB><test name>
#
# Baseline: 254 gates, 235 PASS / 18 FAIL / 1 NOTFOUND on RTX 5070 Ti (sm_120),
# CUDA 13.3, driver 610.43.03, 2026-07-25.
