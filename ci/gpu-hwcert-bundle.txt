# Focused hardware-certification bundle -- roadmap item 2
# ============================================================
#
# ~80 commits between 2026-09-02 and 2026-09-29 moved most of the runtime's
# hand-written PTX into KIR (`crates/nsl-kir/src/kernels/`). Every migration is
# gated by `crates/nsl-codegen/tests/*_kir_equivalence.rs`, which proves on the
# cooperative-CTA INTERPRETER that the KIR kernel leaves the same bytes as its
# frozen predecessor. That is strong evidence and it is not silicon evidence:
#
#  * ptxas contracts an un-rounded `mul` + `add` into `fma` on hardware, which a
#    PTX-semantics interpreter cannot see. `nsl_kir::kernels::norm` records that
#    the hand norm kernels WERE contracted and the KIR ones round twice -- so for
#    those kernels interpreter equivalence and silicon equivalence differ.
#  * A missing barrier is a timing race. The hand LayerNorm had one (a warp could
#    normalize with the VARIANCE partial in place of the mean); KIR fixed it.
#
# This file names the GPU gates that exercise those kernels on the device, so
# they can be run on their own in minutes instead of inside the 400-gate lane:
#
#   NSL_CERT_GATES=ci/gpu-hwcert-bundle.txt \
#   NSL_CERT_OUT=<evidence-dir>/hwcert-report-$(git rev-parse --short HEAD).tsv \
#     scripts/gpu-cert.sh --run
#
# It runs through gpu-cert.sh itself -- same guard, timeouts, per-gate logs and
# known-red verdict. A line naming a gate that is not in the `gpu` tier REFUSES
# the run, so a renamed or re-tiered gate cannot silently leave an area bare.
# Point NSL_CERT_OUT outside the worktree: the per-gate logs are written beside
# the report, and a report inside a worktree dies with it.
#
# Known holes -- listed so nobody reads a green bundle as covering them:
#  * dropout BACKWARD: `dropout_backward_parity_gate.rs::
#    gpu_source_backward_matches_tape_mask_backward` is tiered `broken` for a
#    `nsl_tensor_compare` dtype abort that acd2535c FIXED on 2026-08-25, nine
#    days after the gate was parked. It joins this list once it passes on the
#    device and is re-tiered; until then the filter would (rightly) refuse it.
#  * SpMM (CSR/COO/BSR, which #785 moves to KIR): NO GPU gate exists at all.
#  * `nsl_log_softmax_f32`: no public entry point, no GPU gate.
#  * Performance: nothing here times a kernel. Benchmarks are a separate step.
